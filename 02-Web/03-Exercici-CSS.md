# Exercici001: 

Pàgina web amb estils CSS bàsics

Dóna estils a la pàgina del currículum de l'exericici "HTML".

Les condicions són:

- Fer servir un arxiu `.css` global cridat a les capçaleres de les pàgines amb l'element `link`.

Com a mínim has

- Una tipografía pública per tots els elements de la clase

- Definició de títols i enllaços per selector (`h1`, `h2`, `a`)

- Definició d'estil d'enllaç `:hover``

- Definició d'elements per atribut `class`amb `.`

- Definició d'elements per atribut `id`amb `#`

- Definició d'estils pels elements d'una llista amb `:first-child`, `:last-child`

- Una geraquia combinada tipus `id` > `element` (exemple: #base > li)

- Pseudoelements `::before` i `::after`

## Entrega

Entrega l’exercici com un nou repositori a GitHub anomenat:

```text
DAM1M04-Exercici-CSS
```

Copia l’enllaç del repositori de GitHub a l’espai d’entrega del Moodle de l’assignatura.
